# Преимущества разделения системы на домены

Разделение системы на домены позволит независимо развивать бизнес-направления и компоненты системы

Предлагаемые домены:

| Домен                   | Описание                                                                        |
|-------------------------|---------------------------------------------------------------------------------|
| **Финтех домен**        | Развитие финансовых продуктов: кредиты, платежи, финансовые транзакции          |
| **Медицинский домен**   | Медицинские процессы: работа с пациентами, лаборатория (мед анализы)            |
| **Аналитический домен** | Построение BI отчетов, анализ медицинских данных из DWH                         |
| **ИИ домен**            | Построение AI моделей для выявления закономерностей и прогнозирования диагнозов |
| **Головной домен**      | Операционная деятельность, управление организацией                              |
